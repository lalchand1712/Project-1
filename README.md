# Personal Bucket List

This is a simple HTML page that displays a personal bucket list with a checklist format. The page allows users to see a list of items they may want to achieve in their lifetime, with checkboxes to mark completed items.

## Features
- A visually appealing design with a structured layout.
- Checkboxes to mark completed bucket list items.
- Responsive styling for better user experience on different screen sizes.
- Clean and readable code structure.

## Technologies Used
- **HTML**: For structuring the webpage.
- **CSS**: For styling and layout design.

## File Structure
- `Personal Bucket List Lal Chand Kumawat.html` - The main HTML file containing the bucket list and styling.

## How to Use
1. Open the `Personal Bucket List Lal Chand Kumawat.html` file in any modern web browser.
2. View the list of bucket list items.
3. Check or uncheck items to mark them as completed.

## Customization
You can modify the list by:
- Adding new list items inside the `<ul class="Personal__Bucket__List">` section.
- Changing colors, fonts, and styles in the `<style>` section inside the `<head>`.

## Compatibility
This project works on all modern web browsers including:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari
